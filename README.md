# 项目名
- eatingclient（大口吃饭，不说随便）
## 项目简介
`src/packageA/pages/about/index.jsx`
## 技术栈
- 前端框架：React、Taro
- 状态管理：暂无
- 样式：scss
## 项目结构
- `src/api` - 接口地址和请求方法
- `src/assets` - 项目需要的图片和图片地址
- `src/components` - 公共组件
- `src/packageA` - 项目分包（目前分包策略：不是家庭点餐相关功能的页面都放在分包）
- `src/pages` - 页面组件
- `src/styles` - 公共样式（todo，公共样式暂时还没利用到整个项目，大部分页面样式都是自己的）
- `src/utils` - 公共方法
## 开发规范
- 组件命名：PascalCase（每个单词的首字母大写，包括第一个单词，不使用下划线或连字符作为分隔符。）
- 文件命名：camelCase（驼峰命名）
- 样式使用SCSS模块化
